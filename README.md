# MCM para o Claude

O sistema de trabalho da MyClientMachine dentro do Claude: o Claude passa a saber quem você é, como é o seu negócio e como você escreve, organiza o trabalho em departamentos (o que é contínuo) e projetos (o que tem fim), e guarda o histórico de cada assunto para qualquer conversa continuar de onde a outra parou.

## Como instalar (uma vez só)

1. Use o app do Claude no computador, em um plano pago.
2. Crie uma pasta no seu computador para o sistema (por exemplo, `Documentos/Claude`).
3. No Claude, abra **Personalizar → Plugins → Adicionar → Adicionar marketplace** e cole: `ricacutolo/mcm-claude`
4. Ative o plugin **MCM** e ligue **Sincronizar automaticamente**, para receber as atualizações sozinha.
5. Se o Ricardo te mandou uma pasta chamada `_semente`, coloque ela dentro da pasta do sistema.
6. Abra uma conversa nova, adicione a pasta que você criou e diga: **começar a instalação**.

A instalação vai em etapas curtas. Dá para parar a qualquer momento e voltar dizendo **continuar a instalação**.

## No dia a dia

Converse com a pasta conectada. Alguns jeitos de começar:

- **abre o Conteúdo** — entra no departamento e diz onde parou e o próximo passo
- **me dá ideias de post** · **faz um post pro Instagram sobre…** · **post pro LinkedIn sobre…**
- **escreve na minha voz…** — e-mails, mensagens, textos
- **como está meu dia** — agenda e e-mails importantes
- **novo projeto** · **novo departamento**
- **guarda isso** — guarda algo no histórico do assunto

Sem a pasta conectada, o Claude funciona normal, sem o sistema.

## Segurança

O sistema nunca envia, publica ou apaga nada sozinho. Tudo vira rascunho para você aprovar, e o que seria apagado vai para `_revisao/`.
