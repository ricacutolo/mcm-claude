# Platforms

This edition's posts are written in Brazilian Portuguese; the rules below are in English for Claude, and every caption, title and CTA comes out in Portuguese.

One file per platform the content machine posts to. They ship with the plugin and are **read-only**, like `library.md` and `playbook.md`.

**The switch:** the platforms line in her `departamentos/conteudo/estrategia.md` (Cadence section). A skill reads the file for each platform on that line, and only those. A platform that isn't on is never read, written for, scheduled to or asked about.

Every file has the same sections, so a skill knows where to look:
- **When to recommend it** — for the strategy and setup steps.
- **Account** — which kind of account posts, and how she connects it.
- **Formats** — which formats it takes and how each is sent.
- **Caption** — whether it shares the main caption or gets its own, and the rules.
- **Scheduling** — the GoHighLevel details for `create-post`.
- **Results** — what counts most when the monthly review reads it.

Adding a platform = a new file with these sections, plus its line in the strategy question and the setup step. The skills don't grow.
